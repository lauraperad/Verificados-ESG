# ✅ esg_rag_webapp_final

Uma aplicação web para análise de conformidade com diretrizes ESG (Environmental, Social and Governance) a partir de documentos enviados.

## 📌 Funcionalidades

- Upload de arquivos `.txt` e `.pdf`
- Campo para inserir uma pergunta customizada
- Análise simulada de aderência ao ESG com base no conteúdo do documento
- Interface web simples utilizando FastAPI e Jinja2

## 🛠️ Tecnologias utilizadas

- Python 3.12
- FastAPI
- Jinja2
- PyMuPDF
- HTML/CSS
- Uvicorn
